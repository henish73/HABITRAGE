FinanceOS 2.0 Redesign
FinanceOS 2.0 · Redesign plan

Calm money. Every number earns its place.

A complete redesign of the web and mobile apps around one idea: when you open FinanceOS, you should know within three seconds whether you're okay, what needs you, and what's coming.

ScopeWeb app, iOS and Android, shared design tokens
LookDeep navy and vault teal, Geist with Geist Mono for money
SignatureBalance-sheet bar, 30-day cash runway, card wallet
Size9 phases, about 6–8 weeks for one developer

One answer first

Every screen opens with the one figure that matters there. The details sit under it.

Color means something

Teal for actions, green for money in, brick red for money out and debt, amber for "look at this". Nothing decorative.

Safe by feel

Masked by default, Face ID on mobile, undo for every delete, and AI that asks before it changes anything.

Fewer, better screens

Nine sidebar items become five. Pending holds, credit and analytics move to where you'd look for them.

Signature components

Six pieces that make it feel like one product

Each is built once for web and once for mobile against the same tokens, so they behave and look identical.

CashOwed

Balance-sheet bar

Assets against debts as one split bar. It shows the size of the gap at a glance, which a single net-worth number can't.

Cash runway

Projected cash for 30 days from paydays and bills. The line turns amber below $500 and red below $0, days before it happens.

How it gets built

One set of tokens, two apps

A new packages/design-tokens holds every colour, size, radius and motion value in one file. It generates the CSS variables and Tailwind preset for the web, and a theme object for React Native, so the two apps can't drift apart.

Roadmap

Nine phases, each shippable

Each phase ends with a working app, so you can stop or reorder at any point. Sizes assume one developer.

P0Foundations

3–4 days

Design-tokens package, Geist fonts, shadcn/ui primitives, the money-figure, chip and sheet components. No visible change yet, but everything after builds on it.

P1New shell and navigation

3 days

Navy rail with five sections, ⌘K command bar with real actions, avatar menu for settings, mobile-web bottom bar. Old routes redirect to the new ones.

P2Home

4 days

Balance-sheet bar, "Needs you" list, cash runway (needs a small /api/forecast endpoint), card wallet and latest activity.

P3Activity

5–6 days

Rebuild the transactions page as a virtualised ledger grouped by day, with a review queue, inline category editing, a side sheet for details, saved views and undo.

P4Wallet

4 days

Card wallet with utilization rings, account detail with a 90-day balance chart, and the credit score folded in from the old Credit Reports page.

P5Plan

5 days

Bills calendar, monthly budgets per category, the full runway, and a debt payoff planner (avalanche vs snowball) for your $15.6k of card debt.

P6Copilot

3 days

AI moves into the command bar and a side sheet. Every write comes back as a proposed-action card with balance impact and Confirm.

P7Mobile rebuild

8–10 days

Remove the sample data and connect to the real API, then add Face ID lock, NativeWind theme, the four tabs plus "+", bottom sheets, swipe actions and haptics. Dark mode follows the phone.

P8Polish and accessibility

3 days

Empty and error states, skeletons shaped like their content, contrast and keyboard checks, reduced-motion pass, and screenshot tests for both themes.
