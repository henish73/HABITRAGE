Do these two things today, before anything else.
  1. Revoke your OpenRouter API key in the OpenRouter dashboard and create a new one. The headline bug

Credit card balances flip sign on any edit

The seed stores card balances as debt (positive means you owe money), using the running balance from your statements. But recalculateAccountBalances (packages/db/src/client.ts:667) restarts every account at $0 and adds signed amounts the way a bank account works. As soon as you add, edit or delete one transaction on a card, its debt goes negative and calculateNetWorth drops it with Math.max(0, …). Two cards have already been hit.

High

The JSON store loses data under load and in production

Every change rewrites the whole 3.4 MB file. Importing 500 CSV rows means 500 full rewrites and 500 recalculations. Two requests at once can overwrite each other. In Docker the data folder belongs to root while the app runs as nextjs, so writes fail silently, and Cloud Run wipes the disk on restart anyway.

High

CSV import corrupts data

Lines are split on every comma, so "UBER, TORONTO" shifts the columns. Dates like 10/16/2026 are stored as-is and break sorting and filters. Amounts such as $1,250.00 become 0. A header containing "name" (like "Account Name") is taken as the description. Re-importing a file creates duplicates. Use a real CSV parser (you already depend on csv-parser), normalize dates, and skip duplicates by date + amount + description.

Theme proposal

"Vault": a palette that reads as safe

The current theme is near-black with an electric blue. That works for a dev tool, but money apps earn trust by feeling calm and deliberate. Vault uses a deep navy for structure (banks have used it for a century), a teal-green accent that suggests "protected" and "OK", and an amber warning used sparingly. Positive and negative are a muted green and brick red, so they don't shout. The page you're reading uses the palette in both light and dark mode; switch your system theme to compare.

Making it feel safe

UX patterns that build trust

Safety cues

  • Masked by default, hold the eye icon to peek, re-mask after 30 s
  • Auto-lock after 10 minutes idle (PIN or passkey)
  • "Last synced" timestamp on every balance
  • Activity log: who changed what, when, and from what value
  • Security chips only when true, e.g. "Signed in · this device"

Safe destructive actions

  • Undo toast (8 s) instead of instant deletes
  • Bulk deletes ask you to type the count ("Delete 42")
  • AI actions show a preview card you approve before anything changes
  • Soft-delete with a 30-day trash

Faster everyday use

  • ⌘K command palette that runs actions ("add expense", "go to TD Visa"), not just search
  • Shortcuts: N new, / search, J/K move rows, E edit
  • Inline editing of category and amount, saved instantly
  • Saved views ("Uncategorized this month", "Large outflows")
  • Mobile bottom tabs and a floating "+" button

Modern polish

  • Sparkline of the 90-day balance on each account card
  • Skeletons the same shape as the content they replace
  • Number transitions of 150 ms when values change (off for reduced motion)
  • Empty states that suggest the next step ("Import a CSV")
  • Comfortable/compact density toggle for the table

Suggested order

Plan

  1. Revoke the key, remove it from source, delete txt

    Then add txt, .env* and data/ to both ignore files.

  2. git init and a first commit

    So every later step can be reviewed and rolled back.

  3. Fix the balance engine and repair stored balances

    Opening balances, a per-type sign, a move-between-accounts recalc, then a one-off repair script.

  4. Harden the API

    Zod on every body, parameterized SQL, real 404s, a CSV parser, export escaping, AI actions that need confirmation.

  5. Add authentication, then use Postgres as the only store

    Supabase Auth + middleware; the JSON file becomes an offline cache only.

  6. UI pass

    Vault tokens, mobile nav, dark-mode fixes, a real privacy mask, a summary endpoint, plain-language labels, no fake numbers.

  7. New features

    Utilization alerts and the debt planner first, since they matter most for the current balances.
